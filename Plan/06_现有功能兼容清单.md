# V0.2 现有功能兼容清单

## 1. 使用方法

本清单是大爆炸切换的逐项追踪基线。

每项在实施时记录：

- 新架构实现位置；
- 对应自动测试；
- 对应人工验收记录；
- 与 V0.13 的有意差异；
- 完成状态。

未经用户明确修改范围，标为“保留”的项目不得静默删除。允许修复错误和重构实现，
但最终用户可见结果必须符合冻结外观与本清单。

状态值：

- `未开始`
- `实现中`
- `待验证`
- `通过`
- `有意变更`

## 10. 完成判定

切换前，每个 ID 必须：

1. 有新实现位置；
2. 至少有自动测试或说明为何只能人工验证；
3. 有一次实际验收记录；
4. 状态为 `通过` 或经用户批准的 `有意变更`；
5. 不存在 `未开始`、`实现中` 或 `待验证`。

任何未登记的新功能也必须先加入本清单，再进入 V0.2 切换范围。
