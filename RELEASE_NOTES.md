# WinPool V0.1 Test Preview

WinPool V0.1 is a public, read-only x64 preview for inspecting Windows Storage Spaces and related storage topology.

## Included

- Read-only discovery of storage subsystems, pools, tiers, physical disks, virtual disks, partitions, and mapped network disks.
- Upper operation workspace and lower nested topology workspace.
- Fixed simulation system for demonstrating a complex storage configuration.
- Chinese and English interfaces, light/dark/system themes, and configurable accent colors.
- Portable, unpackaged, self-contained Windows x64 build.

## Safety and limitations

- This release contains no pool creation, initialization, formatting, removal, resize, repair, or other mutating storage command.
- The Real switch demonstrates privilege handling only and does not enable storage modification.
- Create, Test, Monitor, and Development pages are placeholders.
- This release has no installer or in-app updater.

Verify the archive with the attached SHA-256 file before extracting it.

WinPool V0.1 是用于查看 Windows Storage Spaces 及相关存储拓扑的公开只读 x64 测试预览版。

## 当前包含

- 只读扫描存储子系统、存储池、存储层、物理磁盘、虚拟磁盘、分区和映射网络磁盘。
- 上部操作工作区和下部嵌套拓扑工作区。
- 用于展示复杂存储配置的固定模拟系统。
- 中文、English、亮色/暗色/跟随系统主题和可配置主题色。
- 未打包、自包含的 Windows x64 便携版本。

## 安全与限制

- 本版本不包含创建存储池、初始化、格式化、移除、扩容、修复或其他修改型存储命令。
- “真实”开关目前只演示权限处理，不会启用存储修改。
- “创建”“测试”“监控”和“开发”页面仍为空白占位页。
- 本版本不提供安装器或应用内更新。

解压前请使用随附的 SHA-256 文件校验压缩包。
