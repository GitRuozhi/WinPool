## 1. 控制性决定

从已认可设计抄入，执行时不再重开产品争论。

1. 取消当前编辑页。原下区 → **存储结构编辑**。原上区 → **磁盘分区编辑**。
2. 存储结构编辑：左拓扑；右上结构操作；右下池 / 虚拟磁盘 / 分区属性。无底栏。
   撤销、重做、取消放弃所有修改、应用所有修改都在右上。
3. 磁盘分区编辑：磁盘一组控件，分区（或未分配空隙）一组控件。
4. 一份工作副本。右上「应用所有修改」写入。属性没有第二套提交按钮。
5. 实体层跟盘走，没有添加层按钮。空实体层不画。热备、退役是池开关控制的
   可选模拟层。
6. 藏起 PowerShell 模板层仪式：规格在池，用量在虚拟磁盘。
7. **一块虚拟磁盘是 1.0 契约。** 不得创建第二块。已有多块可收到一块（删除多余；
   有数据要确认；不静默合并）。其它情况等开发页命令行，不在 1.0。
8. 结构页创建/修改只支持一个用户分区。勾选框 **创建磁盘时自动创建分区**，默认
   勾选。多分区去磁盘分区编辑。
9. NTFS 与 ReFS 都支持。预填 NTFS 64K。SKU 不允许创建 ReFS 时禁用。
10. 预填交错区 `64K`、HDD Parity 列数 `n` 或 `n−1`、SSD Mirror（仅一块则
    Simple）。256K 组合要警告。这些默认可改。
11. 列数、条带大小、介质、弹性、副本是池属性字段。Journal 与 Manual 不在
    本产品路径。优化和修复留在管理页，不是结构操作。
12. 结构控件一律显示。不能做的禁用；推算值只读灰色。不因未选中而隐藏控件。
13. 工作站与独立服务器共用编辑器。无集群 / S2D / WAC。
14. 仅仿真。真实变更仍拒绝。

## 2. 闭环

本 Plan 完成时，用户可以：

- 打开存储结构编辑和磁盘分区编辑，而不再打开编辑页。
- 按研究默认（除非用户改）创建带介质层的仿真池、一块虚拟磁盘、可选一个
  NTFS 或 ReFS 卷。
- 改成员、给全未划层的池加层、逐出到未划层，并一次应用，草稿不会弹回。
- 把已有多虚拟磁盘的池收到一块。
- 在磁盘分区页用分开的磁盘/分区控件处理未入池磁盘。

这就是最小闭环。不要加第二块虚拟磁盘的创建路径、集群对象、自由命令或真实变更。

## 3. 工作项

按顺序执行。除非开发者改顺序，当前项的检查未通过前不要开始下一项。

| ID | 工作 | 检查 |
| --- | --- | --- |
| PE1 | 导航：去掉编辑；加上存储结构编辑和磁盘分区编辑；双语标签；上次页面恢复仍可用 | 应用能启动；两页能打开；编辑页已消失；进程仍活 |
| PE2 | 磁盘分区编辑：迁入原编辑上区拓扑；磁盘与分区控件拆开 | 选中磁盘只亮磁盘操作；选中分区只亮分区操作 |
| PE3 | 存储结构页骨架：左拓扑；右上按撤销/重做/放弃全部/应用全部、创建/解散池、退役/热备磁盘、创建/删除虚拟磁盘排列；右下属性按控件规格；列出的控件都显示，但性能/容量/专用层字段组仅在该层存在时出现 | 布局符合 §1；不画空实体层 |
| PE4 | 创建组合：选盘、改介质、角色、层、一块虚拟磁盘、自动建分区勾选、NTFS/ReFS、研究预填 | 仿真创建得到一池、一块虚拟磁盘、可选一个用户卷；256K 会警告 |
| PE5 | 修改：加入/逐出/未划层→层、不加空横条也能加层、结构与参数一次应用 | 全未划层回层能提交；表单不悄悄弹回 |
| PE6 | 多虚拟磁盘收到一块；拒绝创建第二块 | 没有创建第二块的控件；有数据的多余盘删除要确认 |
| PE7 | 右上应用所有修改只写入仿真 | 真实系统只读；危险项仍用确认对话框 |
| PE8 | 新页投影与仿真操作测试；两页原生打开 | 点名测试通过；原生：启动 → 各新页 → 进程仍活 → 无新崩溃日志 |
