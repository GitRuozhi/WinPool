## 1. 已确认决定

这些决定优先于当前编辑页实现。它们不能覆盖真实存储变更安全边界。
本阶段所有变更都**只改模拟系统**。

### 1.1 页面骨架

- 上下两半，初始高度 1:1，带行分割条。
- 每个半区**一个**纵向滚动条。两个半区不共用整页滚动。
- 半区没有标题，也不加「逻辑拓扑 / 控件组」标题。
- 每一半：左边拓扑，右边控件组。
- 控件组**固定宽度**。拖窗口改变的是拓扑区大小，和管理页命令区一样。拓扑吃剩余宽度。

### 1.2 上半区

- 左：用管理页那套逻辑拓扑视觉控件（`TopologyNodeControl` 以及现有 Stack / Flow）。
- 右：保留当前分区操作——扩展、压缩、删除、格式化、新建分区、初始化、脱机/联机。
- 投影：
  - 只显示两级：磁盘和分区。不显示系统、池、层。
  - 磁盘竖排。磁盘内分区横排。
  - 显示可分区磁盘。非原始池的物理成员不显示。可分区的虚拟磁盘显示。
  - 未分配空间是磁盘的子节点。若一个分区把未分配区拆成两段，就是**两个**子节点，按偏移空隙算，不是把剩余容量合成一块。
- 系统盘和网络盘是否出现在这个列表里，见 **Q20 / Q21**。

### 1.3 下半区 — 拓扑

- 只显示内部池，包括原始池。不显示网络/外部池。
- 原始池显示到磁盘。没有层，没有分区。
- 存储池显示层、磁盘、虚拟磁盘。虚拟磁盘显示分区。
- 池从左到右排，假加号池在所有池右边。
- 点加号插入**本地草稿**池。执行成功前不写入模拟文档。
- 新草稿池显示：虚拟磁盘「未建立」，性能层空，容量层空。
- SSD → 性能层。HDD → 容量层。
- SCM 使用**专用层**。没有 SCM 盘时隐藏。默认只显 SSD 和 HDD。
- Unknown / 未标明介质：拒绝拖放。
- 拖动只识别**池**，不识别层。松手后磁盘自动进入对应层。
- 拖动只更新编辑页工作副本。**点执行才写入文档**。

### 1.4 下半区 — 控件表

两列：项名 | 项值。选中池后用该池参数填充。加号生成的草稿自动填入推荐参数。

若选中的池有**多个虚拟磁盘**：不允许继续修改，并弹出警告：

> 不推荐在一个 Windows 存储空间内创建多个虚拟磁盘。如确有需要，推荐创建一个虚拟磁盘并创建多个分区。

英文界面用同一含义。

每个层额外增加：列数、冗余副本数量、允许故障盘数，再加上已点名的复原、交织、大小。
增加一键**解散池**按钮。额外行顺序和解散位置见 §3，仍受 Q22–Q31 约束。

### 1.5 执行与创建默认值

- 产品版本保持 **V0.45**。
- 执行和解散只针对**模拟**系统。本机真实清单保持只读。
- 空池：执行保持禁用。
- 对草稿点执行：创建池、虚拟磁盘、分区。分区用 NTFS + 64K 簇，包含模拟格式化。
- 默认值来自 V10 推荐配置，并按磁盘数调整：

| 字段 | 默认 |
| --- | --- |
| 性能层复原 | 镜像；该层只有一块盘时为 **Simple** |
| 性能层副本 | 2；Simple 时为 **1** |
| 性能层交织 | 64K |
| 性能层列数 | Windows 自动（V10：SSD 层不要手动传 `-NumberOfColumns`）。控件行为见 Q26。 |
| 容量层复原 | 奇偶校验；该层只有一块盘时为 **Simple** |
| 容量层物理盘冗余 | 1；Simple 时为 **0** |
| 容量层列数 | 跟 HDD 块数走：同容量 `N = n`，混容量 `N = n − 1`。待 Q23 确认。 |
| 容量层交织 | 64K |
| 分区文件系统 | NTFS |
| 分区簇 | 64K |
| 64K + 64K 研究说明 | 放在簇大小行下面当辅助文字，不是半区标题 |

一块盘回退 Simple 是**按层**算的，与 V10 一致（「SSD 层两块盘用镜像，一块盘用 Simple」）。

### 1.6 修改已有模拟池

选中已有模拟池时加载其参数。用户可改完再执行修改。这会改写模拟文档。
不声称真实 Windows 能对实盘做同样的原地修改。

## 3. 剩余问题回答后的建议形态

本节是映射，不是额外产品范围。

### 3.1 工作副本

当前文档是模拟时，编辑页持有快照的工作副本。拖盘立刻更新该副本和下区拓扑。
执行通过有类型的模拟操作提交工作副本。离开编辑页且未执行则丢弃工作副本。

### 3.2 投影

- `ProjectPartitionWorkspace`：上半区磁盘森林。未分配子节点按偏移空隙计算，包括盘头、盘尾和中间空洞。
- `ProjectPoolWorkspace`：原始池、内部命名池、存在 SCM 时的专用层、然后是加号节点。管理页 `TopologyProjector.Project` 不变。

### 3.3 建议的下区右侧行序

仍受 Q26、Q27、Q31 和 SCM 可见性约束：

1. 执行修改 / 创建新池
2. 解散池（Q31）
3. 池名
4. 虚拟磁盘名
5. 性能层：复原、交织、大小、列数、副本、允许故障盘数
6. SCM 专用层（仅当存在 SCM）：同一组字段
7. 容量层：复原、交织、大小、列数、副本、允许故障盘数
8. 分区文件系统
9. 分区簇大小
10. 64K + 64K 辅助文字

### 3.4 今天还不存在的模拟操作

当前模拟可以建池（必须有成员、不建层）、建虚拟磁盘、移动磁盘、编辑分区。
不能创建存储层，也不能移动已经属于某层的磁盘。

本阶段必须补上，且仍只走模拟：

- 创建带性能/容量（以及需要时的 SCM）层的池；
- 对草稿执行时创建虚拟磁盘 + 分区 + 格式化；
- 执行时提交感知层的磁盘成员；
- 执行修改时改写池 / 层 / 虚拟磁盘参数；
- 解散池，磁盘回原始池。

`StorageTierInfo` 目前有 `NumberOfColumns` 和 `Interleave`，没有副本和允许故障数字段。
若 Q27 需要持久化，这些成为可选快照字段。除非后续回答证明必须改线路或数据库，schema 14 和 IPC protocol 4 保持不变。

物理磁盘拖动源只存在于编辑页下区树。管理页节点保持不可拖。

### 3.5 上区右侧操作

保留当前模拟分区/磁盘操作，由上区拓扑选中项驱动（磁盘、分区或未分配节点）。
点未分配节点走现有新建分区路径。
