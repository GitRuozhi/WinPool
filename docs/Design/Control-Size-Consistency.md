# 全局控件与网格尺寸一致性盘点

状态：用户尺寸方向已纳入当前 [Plan](../Plan.md)，代码已实现并完成 Release 重建与架构测试；原生仅确认结构编辑页初始右栏与分隔槽尺寸，拖拽、窄窗及其余页面仍待验证。下文“原始尺寸”以 `f0e8806`（2026-09-23）的源码为盘点基线，“实施值”以本轮修改为准，原生验收状态见 [Quality](../Quality.md)。原始尺寸表所列行号属于该基线，当前源码行号可能已变化。本文依据 `src/WinPool.App` 的 XAML 与动态控件代码逐页盘点；数值单位均为 DIP。`Height` 是固定高度，`MinHeight` 只是下限，布局槽位高度也不等于其中控件的实际高度。本文不把源码声明冒充运行时实测尺寸。

目标是让**相同角色**的按钮、输入控件、表格行和网格间距遵循同一规则；内容换行、窗口缩放和字体放大仍须能正常布局。当前实现的颜色、圆角与视觉状态见[前端样式核对表](../DesignTables/Styles.html)，控件用途见[控件说明](../DesignTables/Controls.md)。

按用户最新决定，应用自建 `Button` 只分两类：**图标＋文字的普通按钮**，以及与字段同行的**单图标按钮**。管理页“编辑存储池”、编辑页“联机／脱机”、分区页“新建分区／格式化分区”和设置页图标文字按钮采用同一普通按钮规则；“操作区”只是页面位置，不是第三种按钮样式。

## 已确认并实施的尺寸规则（待原生验证）

| 角色 | 实施基准 | 应用范围与保留的弹性 |
| --- | --- | --- |
| 常规表单控件 | 最小高 32 | `TextBox`、`ComboBox`、`NumberBox`；同一行使用共同最小行高及垂直居中。文字放大或翻译换行时允许整行增高。 |
| 图标文字普通按钮 | 最小高 32，统一内边距与圆角 | 管理、硬件、编辑、监控、设置和欢迎页的自建普通 `Button` 共用同一基线；位置不另派生操作区高度。文字换行时按钮与所在行按内容增高。 |
| 属性字段行 | `Auto + MinHeight=40`，控件 `MinHeight=32` | 把结构页固定 40 行和固定 32 控件改成可随文字放大的下限；分区页 Auto 行引入相同下限。标签／值需有换行与列宽策略；容量第二行等复合字段按内容增加高度。`ToggleSwitch` 保留原生轨道尺寸，只统一所在行及中线。 |
| 行内单图标按钮 | 32×32，图标槽宽 32 | 重置、MAX、拓扑展开、关闭及单图形选择等紧凑按钮归入这一类；色块展示不强制改成文字按钮。 |
| 编辑页操作块布局 | 槽位最小高 44，内含普通按钮 | 176×44 是目前固定**网格槽位**，不代表第三种按钮高度。实施时槽位按同行最长内容共同增高，内含按钮仍使用全局普通按钮基线。 |
| 比较／报告表行 | 最小高 32 | 管理与硬件共同使用；长值换行时整行同步增高，不给硬件标签另设 34。监控行含 32 DIP 色块命中区，初始表高估算按每行约 41 DIP，用户仍可拖动分隔槽调整。 |
| 拖拽分隔槽 | 8 | 管理、监控、开发页及两个编辑页的区域分隔统一可拖且命中厚度相同；管理页 6 宽列分隔改到同档前核对 480 宽布局。普通卡片之间的留白不是分隔槽。 |
| 页面与卡片留白 | 沿用既有密度和业务布局 | 设置／开发／监控等页面仍用约 24 DIP 外边距，管理／硬件等高密度页仍用约 12 DIP；本轮只统一真正的区域分隔槽，不把卡片边距或 6／10／20 DIP 的内部空隙一律改成拖拽槽。 |
| 专用自适应视觉 | 维持各自语义尺寸 | 48 标题栏、28 消息行、拓扑节点、28 色格、384 宽自然高通知、文本详情弹层、监控图表及可拖区域比例不强行等高或等宽。 |

字段**列宽**按内容语义统一：同一张表的表头和数据行共享同一列定义；同一编辑表单的标签／图标／值共享列定义；跨页面不把属性标签列、监控数据列和拓扑几何强制设为相同像素。结构与分区编辑页右栏都从 **320 DIP** 开始，由可拖分隔槽调整；属性表单按栏宽分配弹性标签／值列。分区起点和终点各在单行显示，借用空闲复位列保留完整数值，两组数字分别右对齐。

## 本轮具体取舍

- 编辑页的 44 DIP 仅为操作块**最小布局槽高**，普通按钮本体沿用统一样式。`FixedWrapPanel` 按同行最高内容增高；操作区在窄窗横向滚动以保留 176 DIP 按钮槽宽，并以 220 DIP 高度上限及纵向滚动防止多行按钮挤掉拓扑区。结构页待处理列表的内容区上限为 96 DIP。
- 设置页保持双列，标签列为 160 DIP，值列占剩余空间；主题／强调色／语言下拉宽 220 DIP，路径／7Z 下拉宽 180 DIP，避免宽窗口拉长项名和下拉。路径选择、行内图标按钮与可省略的路径文本保持同行。480 DIP 可达性还需原生核对。
- 颜色预览按钮以单图形行内按钮处理，保留色块图形而统一命中尺寸；拓扑展开、重置和 MAX 同属 32×32 单图标按钮。图表内部纯展示色条不是按钮。
- 两个编辑页右栏初始 320 DIP、最小 240 DIP，左栏最小 120 DIP；可以向两边拖动。右栏表单随当前宽度布局，不出现表单横向滚动；分区起点和终点各保留单行，普通属性行最小高 40 DIP、行距 4 DIP，容量复合行自然增高。拖动结果不写入设置，页面重新创建时回到默认 320 DIP。
- 页面外边距仍按内容密度保留已有 12／24 DIP 档；实际分屏槽统一 8 DIP。普通卡片留白不提供拖拽。宽窄窗口和中英文换行须在原生界面核对。
