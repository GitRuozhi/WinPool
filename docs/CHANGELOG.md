这里只记录重要结果与当前限制，开发过程由 Git 保存。活动阶段见 [Plan](Plan.md)（V0.50，待用户批准，尚未实施）；当前代码仍为 V0.49。2026-09-10 以前的完整历史保存在[英文原件](Archive/20260910-documentation-reset/original/docs/CHANGELOG.md)和[中文原件](Archive/20260910-documentation-reset/original/docs/CHANGELOG.zh-CN.md)，不追溯改写。

## 2026-09-10：内置模拟系统校正

内置模拟布局改为可展示、可测编辑器边界的一组：建池原料、标准两层池、三层池（SCM+SSD+HDD）、超多分区系统盘、超多磁盘服务器（40+ 物理盘）、空池、单盘池、热备与退役、双虚拟磁盘、分区边界、其它与网络；保留 DESKTOP-PL96UKD。分区偏移累加、盘符全局唯一、层介质与热备 Usage 对齐。

## V0.49：磁盘分区页及时生效与格式化属性

- 分区页改为格式化/卷属性工作区：动作条在拓扑左下横排，右侧属性跟随选中对象；去掉撤销/重做/放弃/应用全部。每次允许的动作单独经 Agent 提交，弹出成功或失败。未初始化磁盘不画分区；选中后点新建分区会提示先初始化。未分配上的格式化按钮改为创建新分区；本程序新建分区自动格式化，已有未格式化分区仍显示。仿真中可选分区均可删除（含 EFI/MSR/恢复/未知类型），删除前确认。
- 模拟格式化支持 NTFS、ReFS、exFAT；NTFS 默认；ReFS 先确认证据限制。快速格式化走同一 `FormatPartition`，同样弹结果。不格式化则只建无卷分区。
- 打开资源管理器只对本机真实卷。扩展/收缩按钮占位，不改大小。结构页仍为统一草稿。
- 内部格式仍为 schema 15 / IPC 5 / document 2 / snapshot 3。真实存储结构修改继续拒绝。
- 自动测试 467 项通过；依赖审计无已知漏洞包。WinUI、完整设备、DPI、高对比度、托盘与长期运行仍为 unverified。阶段计划见 [V0.49 归档](Archive/V0.49/README.md)。

## V0.48：模拟语义、存储模型与提交链路

- 独立 Volume 实体；Partition 只保留几何与类型；用途以 PhysicalDisk Usage 为单一事实，Retired/HotSpare 为其投影。
- 统一规则入口与 Fixed 布局保守估算（先按副本折算，再扣 1% 规划余量并对齐）；单盘 Mirror 拒绝；新建只走 GPT；扩缩容在缺少 Windows supported-size 时标明尚不支持。
- 草稿一次生成不可变操作序列，预览与应用共用；新对象 ID 在规划时分配。修复 B1（误删新建虚拟磁盘）和 B2（仅分区改动被跳过）。
- 提交带稳定 CommitId；回复丢失时对账，已提交则重载，未提交才允许重试。Optimize 为明确的模拟无操作，不声称测得性能改善。
- 内部格式切换为 SQLite schema 15、IPC 5、StorageSystemDocument 2、StorageSnapshot 3；旧格式拒绝，无迁移。
- 2026-09-10 用户确认带成员的建池/改池可用并结束阶段。自动测试 460 项通过。完整设备、DPI、高对比度、托盘与长期运行仍为 unverified。真实存储结构修改继续拒绝。阶段计划见 [V0.48 归档](Archive/V0.48/README.md)。
- 结构页应用失败会显示原因并保留草稿与撤销；提交结果未知时仍重载已保存状态。分区页撤销/应用按钮空闲时仍可能显示可用。

## V0.47：当前实现状态与已知限制

两页模拟编辑和后续控件/属性改动已在 `main`，不能继续描述为“控件计划尚未实施”。拆页阶段的原始记录见 [V0.47-editor-pages](Archive/V0.47-editor-pages/Plan.md)，其原生 PE8 等未取得证据仍保持未验证。

2026-09-10 在代码基线 `39f0d4e` 的审查发现：

- 新池自动创建的虚拟磁盘可能被后续提交序列误删。
- 只有分区变化时，统一提交可能跳过分区操作。
- Agent 提交后回复丢失，App 可能误报失败且未改变，实际持久化已成功。
- 部分模拟容量把物理成员容量直接当逻辑容量；新对象关联及新增字段采集贯通不完整。

这些问题尚未修复，具体回归要求见 V0.48 Plan。旧代码的 449 项自动测试、隔离 Release 构建和依赖审计在此前审查通过，但不足以证明模型与 Windows 一致，也不代表文档重构后的现有测试已通过。完整人工与真实设备验收没有因此完成。

真实存储结构修改继续拒绝，相关开发留到 V0.5x。
