# 磁盘分区编辑页控件

临时稿。不是 Plan。

左拓扑两层：磁盘，以及其上的分区 / 未分配空隙。右上动作。右下分区属性 / 格式化选项。无底栏。无撤销 / 重做 / 放弃 / 应用全部。无保存属性按钮。

列出的控件默认都显示，不能做的禁用。当前不是仿真时，右上和右下禁用。点右上即写入仿真；破坏性操作先确认。

本页不改存储池结构。入池、分层、创建虚拟磁盘在存储结构编辑页。

---

## 右上

先横排再竖排：组内从左到右，组与组从上到下。

```text
联机    脱机    初始化    转换为 GPT
新建分区    删除分区    扩展    收缩    打开资源管理器
```

| 按钮 | 禁用 | 行为 |
| --- | --- | --- |
| 联机 | 未选盘、已联机 | 联机 |
| 脱机 | 未选盘、已脱机、系统/启动盘 | 脱机。页面文件/转储先去角色 |
| 初始化 | 未选盘、已有分区表 | 写成 GPT。没有 MBR |
| 转换为 GPT | 未选盘、已是 GPT、盘上还有分区 | 空盘转为 GPT。不能转为 MBR |
| 新建分区 | 未选未分配空隙 | 按右下容量在空隙建分区。文件系统不是「不格式化」时按右下规格格式化 |
| 删除分区 | 未选用户分区 | 有数据须确认。EFI / MSR / 恢复禁用 |
| 扩展 | 未选用户分区、右侧无相邻空隙 | 扩到右下容量 |
| 收缩 | 未选用户分区、不能再小 | 收到右下容量 |
| 打开资源管理器 | 没有盘符、RAW、脱机 | 打开该卷 |

---

## 右下

顺序固定。项-值。最后一行整宽 **格式化**。只有这一颗按钮。

| 字段 | 控件 | 默认 | 何时灰 / 禁用 |
| --- | --- | --- | --- |
| 盘符 | 无 / D–Z | 下一个空闲 | 无卷时禁用；已被占用的不出现。改了即生效，不必格式化 |
| 卷标 | 文本 | 空 | 无卷时禁用。改了即生效，不必格式化 |
| 容量 | GB | 空隙=Max；已有分区=当前大小 | 给新建 / 扩展 / 收缩用 |
| 文件系统 | NTFS / ReFS / exFAT / 不格式化 | NTFS | SKU 不能建 ReFS 则禁用 ReFS。「不格式化」时「格式化」禁用 |
| 分配单元 | 4K / 8K / 16K / 32K / 64K | 64K | 「不格式化」时禁用 |
| 快速格式化 | 开关 | 开 | 「不格式化」时禁用 |

**格式化：** 用当前文件系统、分配单元、快速格式化开关格式化选中分区。有数据须确认。系统分区禁用。ReFS 先确认。选「不格式化」或未选用户分区时禁用。

磁盘没有属性区。

---

## 拓扑

一条磁盘一行。段是分区和未分配空隙。空隙要画，否则无法选中去新建。

入池物理盘不画。系统 / 启动 / EFI / MSR / 恢复分区要画，破坏性动作禁用。

本页不拖盘入池，不拖分区边来扩缩。

---

## 故意不做

- 动态磁盘，跨区 / 带区 / 镜像 / RAID-5
- 新建 MBR 分区表，转换为 MBR。已有 MBR 盘仍显示，可改分区；空盘只能转为 GPT
- 虚拟硬盘（创建 / 附加 / 分离 VHD）
- FAT / FAT32、挂载路径、标为活动
- 优化、修复、检查错误
