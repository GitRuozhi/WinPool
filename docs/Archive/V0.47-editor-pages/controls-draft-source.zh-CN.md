# 存储结构编辑页控件

左拓扑。右上结构操作。右下属性。无底栏。右上按钮、池分段、磁盘与分段默认都显示，不按选中隐藏。性能层 / 容量层 / 专用层仅在该层存在时显示。不能用的禁用；推算值只读并显示为灰色。

真实模式：右上、右下均禁用。

---

## A. 右上结构操作

全部默认显示。先横排、再竖排：每一组占一行，组内按钮从左到右；组与组从上到下。

```text
撤销    重做    取消放弃所有修改    应用所有修改
创建池  解散池
退役物理磁盘  热备物理磁盘
创建虚拟磁盘  删除虚拟磁盘
```

### 草稿

| 按钮 | 禁用 | 行为 |
| --- | --- | --- |
| 撤销 | 没有上一步草稿 | 撤销一步草稿（拓扑拖盘、属性改动、下面的结构按钮） |
| 重做 | 没有可重做的一步 | 重做一步 |
| 取消放弃所有修改 | 没有未应用的修改 | 草稿回到上次已应用状态 |
| 应用所有修改 | 没有未应用的修改，或非仿真 | 把当前草稿写入仿真文档。256K 条带、ReFS、入池清数据、删除有数据的虚拟磁盘、解散已提交池：先确认对话框 |

### 池

| 按钮 | 禁用 | 行为 |
| --- | --- | --- |
| 创建池 | 已有未应用的草稿池，或非仿真 | 插入一份空草稿池，名称预填。拖入磁盘后按介质自动建实体层 |
| 解散池 | 当前池是 primordial 或不存在，或非仿真 | 草稿池：丢掉该草稿。已提交池：确认后进草稿，点「应用所有修改」时解散 |

### 物理磁盘

| 按钮 | 禁用 | 行为 |
| --- | --- | --- |
| 退役物理磁盘 | 未选中池内物理盘，或该盘已在退役层，或系统/启动盘，或非仿真 | 该盘进入退役模拟层，并打开「显示退役层」 |
| 热备物理磁盘 | 未选中池内物理盘，或该盘已在热备层，或系统/启动盘，或非仿真 | 该盘进入热备模拟层，并打开「显示热备层」 |

页面文件/崩溃转储：先确认去掉该角色，再退役或热备。

### 虚拟磁盘

| 按钮 | 禁用 | 行为 |
| --- | --- | --- |
| 创建虚拟磁盘 | 当前池已有虚拟磁盘，或非仿真 | 仅当前池没有虚拟磁盘时可用。按右下属性创建这一块 |
| 删除虚拟磁盘 | 当前池没有虚拟磁盘，或非仿真 | 删除选中的虚拟磁盘，含最后一块。有已用数据须确认 |

## B. 右下属性

每行一项：左标签、右值（输入框、选择框或开关）。池、层、磁盘与分区各组之间留缝隙。默认输入框或选择框。只读推算值灰色。

表末单独一行：「保存池属性修改」，按钮拉满该行。写入当前池在右下已改的属性。结构成员、创建/解散/删盘仍走右上「应用所有修改」。

### 池

| 字段 | 控件 | 默认 | 何时灰 / 禁用 |
| --- | --- | --- | --- |
| 池名 | 文本框 | PoolNN | |
| 虚拟磁盘名 | 文本框 | 同池名 | 尚无虚拟磁盘且未点创建时仍显示，可先填 |
| 卷名 | 文本框 | 同虚拟磁盘名 | 「自动创建分区」关闭时禁用 |
| 自动创建分区 | 开关 | 开 | 已有虚拟磁盘时禁用 |
| 显示热备层 | 开关 | 关 | 热备层上仍有盘时不能关 |
| 显示退役层 | 开关 | 关 | 退役层上仍有盘时不能关 |

打开「显示热备层 / 显示退役层」后，拓扑画出对应模拟层（无盘也画，供拖入）。拖入与右上「热备物理磁盘 / 退役物理磁盘」同一效果。

### 性能层 / 容量层 / 专用层

三层用同一组字段。有该层才画出这一段，没有就不画。

出现条件：性能层 = 池内已有 SSD 数据盘；容量层 = 已有 HDD 数据盘；专用层 = 已有 SCM 数据盘。第一块对应介质的数据盘进池时自动出现该段；最后一块离开后整段去掉。

| 字段 | 控件 | 默认 | 何时灰 / 禁用 |
| --- | --- | --- | --- |
| 容量 | 输入框（GB） | Max（该层数据盘可用于该层的最大值） | 可改小，不能大于 Max。有存储数据时禁用放大以外的改小到已用以下 |
| 预配类型 | 选择框 Fixed / Thin | Fixed | 有实体层时只读灰（Fixed） |
| 弹性 | 选择框 Simple / Mirror / Parity | 性能/专用：盘数≥2 为 Mirror，=1 为 Simple。容量：Parity | 有存储数据时禁用 |
| 冗余副本数 | 输入框 | Mirror=2 | Simple 时只读灰为 1；有存储数据时禁用 |
| 容灾故障数 | 输入框 | Mirror 为副本数−1；Parity 为 1 | 由弹性/副本推算时只读灰；Parity 时可改；有存储数据时禁用 |
| 物理磁盘数 | 输入框 | 该层当前数据盘块数 | 只读灰 |
| 列数 | 输入框 | 性能/专用 Mirror：由副本与盘数推算。容量：等容量=盘数，混容量=盘数−1 | Mirror 默认只读灰；可改为手动；有存储数据时禁用 |
| 条带大小 | 选择框 16K / 32K / 64K / 128K / 256K | 64K | 有存储数据时禁用。选 256K 时应用须确认 |

### 磁盘与分区

| 字段 | 控件 | 默认 | 何时灰 / 禁用 |
| --- | --- | --- | --- |
| 分区表 | 选择框 GPT / MBR | GPT | 已有虚拟磁盘且已初始化时只读灰。「自动创建分区」关闭且尚未创建盘时仍可改 |
| 文件系统 | 选择框 NTFS / ReFS | NTFS | 「自动创建分区」关闭时禁用。SKU 不能创建 ReFS 时 ReFS 禁用。有存储数据时只读灰。选 ReFS 时应用须确认 |
| 分配单元 | 选择框 4K / 8K / 16K / 32K / 64K | 64K | 「自动创建分区」关闭时禁用。有存储数据时只读灰 |

多于一个用户分区：文件系统、分配单元只读灰，不在本页改。

---

## 左：拓扑

- 拖入池 = 数据盘，按介质进入实体层（自动创建该层）。
- 实体层只在有数据盘时绘制。
- 模拟层仅在对应开关打开时绘制；打开时无盘也绘制。
- 撤销/重做/放弃/应用针对整页草稿，含拓扑拖盘。
