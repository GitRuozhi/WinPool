# WinPool V0.2 安全阻断门证据矩阵

## 1. 用途

本文件把 `03_执行器端口与安全模型.md` 第 15 节的 20 个强制安全测试逐项绑定到
当前工作树证据。`A` 表示自动化证据，`E` 表示仍需要真实进程、UAC 或 GUI 环境验收。
自动化通过不替代真实验收，也不授权执行存储结构修改、真实 R3 动作或工具安装。

## 3. 本轮加固结论

- Windows 临时清理端口在实际删除前重新检查完整祖先路径的 reparse point，并重新调用
  Windows Resource Protection 检测器；审阅后替换父目录为符号链接不会删除重定向目标。
- PowerShell 运行器不再接受字符串脚本或命令参数。唯一公开执行方法是封闭的
  `RunInventoryAsync(CancellationToken)`，实际脚本由 Windows Infrastructure 内部固定选择。
- 当前剩余安全阻断主要是 E 类真实托盘、UAC、RAMMap、调度、电源计划和崩溃恢复验收，
  以及三项需要用户确认的隐私/采集策略；自动化矩阵本身不能将这些项目改判为完成。
