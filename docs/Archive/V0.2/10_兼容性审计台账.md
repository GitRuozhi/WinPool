# WinPool V0.2 兼容性审计台账

## 1. 用途

本文件逐项覆盖 `06_现有功能兼容清单.md` 的 205 个 ID，用于防止“大爆炸重写”
遗漏已有能力。这里的第一轮结论只回答“当前证据处于哪一层”，不把已有代码、自动
测试或 V0.13 旧实现直接算作 V0.2 验收通过。

证据层级：

- `A`：新架构已有实现和自动测试，仍需至少一次实际验收；
- `B`：新架构已部分实现，存在明确缺口；
- `C`：V0.13 活动前端仍保留该能力，但尚未完成新 contracts 迁移和逐项人工回归；
- `D`：尚无满足 V0.2 要求的实现；
- `E`：必须依靠 GUI、UAC、真实外部工具或长周期环境完成的实际验收。

所有条目当前状态仍为 `实现中` 或 `待验证`。只有补齐实现位置、自动测试或人工理由、
实际验收记录后，才可改为 `通过`。
