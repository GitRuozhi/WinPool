# V0.52 硬件页显示修订

状态：待审查，未实施。作为现有 V0.52 计划的界面补充，批准后并入唯一活动 `docs/Plan.md`；不新增重构阶段。本稿替代此前冲突的硬件页布局与删减建议。

## 1. 目标与边界

将硬件页改为旧输出风格的基本硬件报告，以用户提供的《脱敏.txt》为内容基线，以管理页现有表格为视觉基线。只改展示和必要的数据接线；不重构采集器、数据库或主导航，不增加编辑、硬件模拟及真实存储写入。

## 2. 页面样式

- 页头只有“刷新”“导出”两个按钮，沿用当前系统选择。正文按大类纵向排列，不加页内导航、概览卡片、告警面板或快捷操作区。
- **所有表格不显示表头**：不出现“属性／本机／模组 1／显卡 1”等列标题；保留大类标题和正文中的名称、型号等数据行。
- 属性在行、对象在列。复用管理页的字体、行高、列宽、间距、分隔、滚动及窄窗口处理；不横竖切换，不改成设备卡片。对象按内部身份固定对应，各属性不得自行排序导致错列。
- 单项与多项在同一大类内分段排版。Memory 的插槽总数、已用插槽、ECC 单独一段；各模组属性另起一段。**总体值不能挂在第一条设备记录上，也不能重复填入各设备列。** 两段均无表头、使用相同样式。
- 正文显示友好名称和格式化值；标准项名、原值、来源和原因放属性详情，不逐行常驻 `MSFT_*`、`Returned` 或展开框。详情可键盘访问，不增加第三个页头按钮。

## 3. 内容范围

除下述存储缩减及删除“国家或地区、时区”外，不再擅自精简附件内容。保留大类名称及相对顺序，不合并 Computer/System、Memory/VirtualMemory。

- **Computer**：主机名、制造商、型号、架构。
- **System**：名称、版本、内部版本、激活状态、语言、当前用户、本地超级管理员、电源计划。
- **Mainboard**：型号、主板厂商、BIOS 模式、版本、厂商。
- **CPU**：型号、基准速度、物理核心、逻辑核心、一至三级缓存。
- **Memory**：总体信息及模组容量、速度、代际、型号；按 §2 分段。
- **VirtualMemory**：初始大小、最大值、页面文件位置。
- **GPU**：型号、驱动、专用/共享/总计显存、DirectX、总线/设备/功能。
- **Monitor**：型号、制造商、连接显卡、水平/垂直坐标、主显示器、水平/垂直分辨率、刷新率、位深、颜色格式、动态范围。
- **Network**：名称、硬件、链路速度、IPv4、IPv6、MAC、主网络。

**存储部分按本轮决定缩减：**不再展开 Volume、Disk、Storage 的设备、卷、池、层明细。在原存储区域仅保留 Storage 摘要，复用管理页“系统”选项中的存储项目：本地存储容量、外部存储容量、存储池数、物理磁盘数、虚拟磁盘数、分区数、可访问卷数。项目顺序、统计口径和条件显示与管理页一致，不另写一套统计；不在此重复系统版本、CPU 和内存。

上述存储基线取自 `ManageComparisonProjector` 的 `System` 分支；实施时核对最新代码。非存储大类不因这一例外而合并或进一步删减。

缺失、未知、不适用、读取失败和实际零值按现有状态区分；采不到的项目不静默删除、不补默认值。附件仅是内容与排版样例，不硬编码其中配置，不把历史样例值当当前采集结果。保留多设备、软件渲染器与虚拟适配器，沿用隐私规则。

## 4. 数据与按钮

页面读取当前所选系统的统一模型，存储摘要复用管理页投影；不在 UI 匹配来源或重新统合属性。已有字段缺少展示接线时补接线，底层确实未取得的信息如实显示状态，不借机扩大采集范围。

“刷新”复用已有只读硬件刷新；模拟/导入系统不得被本机采集覆盖。“导出”仅输出 JSON，复用管理页系统 JSON 导出的结构、序列化、脱敏、命名和保存流程，导出当前所选系统；不另造硬件报告格式，不接成分类 CSV，不因页面缩减而删除系统文档中的存储事实。

## 5. 修改与验收

先核对管理页表格及 JSON 导出入口，再替换硬件页排版、接入存储摘要和导出；复用现有组件，不改管理页行为。

- 对照附件逐项检查非存储内容，确认大类独立、多设备不错列、单项不占第一设备列。
- 对照管理页确认无表头、样式和窄窗行为一致；存储仅保留系统摘要且数值一致。
- 验证刷新、切换系统、缺失状态、中文/英文、键盘访问和 JSON 导出；导出遵守脱敏，取消保存不报成功。
- 提供实际 WinUI 页面及内存分段截图供审查；完成相关行为测试和构建。不以“字段能展开”代替界面验收，不以浏览器页面代替 WinUI。

按 `AGENTS.md`、Development、Quality 处理代码、验证与文档；仅纯文档编制时不运行程序测试。未实测项记录 `unverified`，不得宣称界面已通过。
