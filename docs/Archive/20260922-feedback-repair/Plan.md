# V0.55 人工检查反馈修复

状态：实现及有限验证完成；部分原生场景受工具前台限制，保持 unverified，非全量验收。基线：`b64382b`。本轮不另行增加版本号。

## 当前决定

- 移除通知横幅，业务消息统一进入右下角简洁卡片；监控同一持续故障不按轮询反复弹出。
- 独立重复消息不合并；卡片不显示详情或关闭按钮。普通消息暂定 8 秒自动消失、点击消失；错误暂定 20 秒自动消失、点击打开错误消息对话框。
- 错误提示进入开发页查看详情。详细记录留开发页；开发者模式关闭时仍隐藏开发页，不增加开启提示或判断。
- 灰色按钮通过悬停提示说明禁用原因，不在按钮外堆放灰色说明；可用按钮补充用途说明。
- 修复模拟系统导入、导出、删除及不合理禁用；真实存储修改仍不开放。
- 系统分区禁止删除、格式化，不能将系统盘保护扩展为所有对象及操作一律禁用；不借修复新增未实现操作。
- 自动创建虚拟磁盘、自动创建分区属于软件偏好，不随当前对象选择改变。
- 同窗口对话框串行属于内部防冲突，不是新增用户入口，并检查对既有操作的影响。

## 已定位并修复的问题

- 管理员运行下，导入/导出仍使用不支持提升模式的旧 `Windows.Storage.Pickers`；迁移到项目已经使用的 Windows App SDK 文件选择器，同类 CSV 导出一并修复。
- 内置模拟被命令投影明确禁止删除，启动又会补回缺失样例。增加最小首次播种标记，删除后不自动重建；显式恢复默认仍能恢复样例。持久化成功前不改内存目录。
- `d6076a`（2026-09-11）将系统/启动标志用于所有分区编辑按钮，范围过宽；V0.55 的外部灰字进一步暴露了笼统禁用理由。
- 当前标准数据根 Diagnostics 只有既有监控日志；管理操作异常目前只留内存消息详情，不能将磁盘日志未记录误判为操作未失败。

## 验收

1. 为重复通知、超时与点击交互、监控状态变化补回归，确保历史保持轻量有界。
2. 模拟系统导入导出往返、删除及失败反馈；准确定位禁用来源，不以修改提示文案代替操作恢复。
3. 系统分区保护与其他允许操作分别回归，真实存储安全边界不变。
4. 自动创建偏好跨对象选择和重载保持；灰色按钮原生悬停可见，常用按钮用途提示可见。
5. 统一相关测试及 Release 构建；原生验证仅使用隔离模拟数据，不修改真实存储。
6. 主代理审阅结果后同步产品/技术/质量文档，记录未验证限制，再归档本计划及本地提交，不推送。
