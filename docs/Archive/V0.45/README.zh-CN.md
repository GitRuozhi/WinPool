这是冻结的 V0.45 编辑页拓扑工作区计划。编辑页改为上下两个独立滚动的半区：上半区
是磁盘/分区工作区，未分配空隙按段拆节点并保留原有分区操作；下半区是池工作区，
原始池只显示磁盘、合成加号池排在最后、工作副本拖盘自动进 SSD/HDD/SCM 层、
按 V10 推荐分层池默认值、执行创建/修改、解散池回原始池。全部操作仅走模拟。

验收时验证（2026-09-04）：合并后的 `main` 上完整 Release 自动门通过 369 个测试，
0 失败、0 跳过；Release 构建 0 警告；无已知漏洞依赖。目标 Application 测试覆盖
两种投影、空隙未分配节点、自动分层、拒绝未知介质、分层创建、解散、以及多虚拟
磁盘禁止修改。开发者确认了原生编辑页点选。
