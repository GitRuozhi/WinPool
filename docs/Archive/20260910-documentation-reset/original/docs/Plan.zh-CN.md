## 1. 页面

左拓扑。右上结构操作。右下属性。无底栏。当前系统不是仿真时，右上和右下禁用。

列出的控件保持显示；性能/容量/专用层字段组仅在该层存在时出现。不能做的禁用。
推算值只读灰色。

## 2. 右上

全部显示。按组横排再竖排：

```text
撤销    重做    取消放弃所有修改    应用所有修改
创建池  解散池
退役物理磁盘  热备物理磁盘
创建虚拟磁盘  删除虚拟磁盘
```

| 按钮 | 禁用 | 行为 |
| --- | --- | --- |
| 撤销 | 没有上一步草稿 | 撤销一步（拓扑、属性、结构按钮） |
| 重做 | 没有可重做的一步 | 重做一步 |
| 取消放弃所有修改 | 没有未应用的修改 | 回到上次已应用快照 |
| 应用所有修改 | 没有未应用的修改，或当前不是仿真 | 写入仿真文档。256K 条带、ReFS、入池清数据、删除有数据的虚拟磁盘、解散已提交池：先确认 |
| 创建池 | 已有草稿池，或当前不是仿真 | 插入空草稿池。拖入的盘按介质进实体层 |
| 解散池 | 没有非 primordial 池，或当前不是仿真 | 草稿池丢掉。已提交池确认后进草稿，点应用所有修改时解散 |
| 退役物理磁盘 | 未选中池内盘、已在退役层、系统/启动盘，或当前不是仿真 | 进入退役模拟层并打开「显示退役层」。页面文件/转储先去角色 |
| 热备物理磁盘 | 未选中池内盘、已在热备层、系统/启动盘，或当前不是仿真 | 进入热备模拟层并打开「显示热备层」 |
| 创建虚拟磁盘 | 当前池已有虚拟磁盘，或当前不是仿真 | 按右下属性创建这一块 |
| 删除虚拟磁盘 | 当前池没有虚拟磁盘，或当前不是仿真 | 删除选中的虚拟磁盘，含最后一块。有数据须确认 |

本页没有执行修改、确认池属性、添加层、优化、修复。优化和修复留在管理页。

## 3. 右下

每行左标签右值。池、各实体层、磁盘与分区之间留缝。最后一行整宽「保存池属性修改」，写入右下已改属性。成员、创建、解散、删盘仍走「应用所有修改」。

### 池

| 字段 | 控件 | 默认 | 何时灰 / 禁用 |
| --- | --- | --- | --- |
| 池名 | 文本框 | PoolNN | |
| 虚拟磁盘名 | 文本框 | 同池名 | 尚未有盘也可先填 |
| 卷名 | 文本框 | 同虚拟磁盘名 | 自动创建分区关闭时禁用 |
| 自动创建分区 | 开关 | 开 | 已有虚拟磁盘时禁用 |
| 显示热备层 | 开关 | 关 | 该层仍有盘时不能关 |
| 显示退役层 | 开关 | 关 | 该层仍有盘时不能关 |

开关打开后拓扑画出对应模拟层（无盘也画）。拖入与右上退役/热备相同。

### 性能层 / 容量层 / 专用层

同一组字段。有该层才画这一段。性能层 = 已有 SSD 数据盘；容量层 = HDD；专用层 = SCM。

| 字段 | 控件 | 默认 | 何时灰 / 禁用 |
| --- | --- | --- | --- |
| 容量 | GB 输入框 | Max | 可改小，不能大于 Max |
| 预配类型 | Fixed / Thin | Fixed | 有实体层时只读灰 Fixed |
| 弹性 | Simple / Mirror / Parity | 性能/专用：≥2 盘 Mirror，1 盘 Simple。容量：Parity | 有存储数据时禁用 |
| 冗余副本数 | 输入框 | Mirror=2 | Simple 时只读灰 1 |
| 容灾故障数 | 输入框 | Mirror 为副本数−1；Parity 为 1 | 推算时只读灰 |
| 物理磁盘数 | 输入框 | 该层当前数据盘块数 | 只读灰 |
| 列数 | 输入框 | Mirror 由副本与盘数推算；容量 n 或 n−1 | Mirror 默认只读灰 |
| 条带大小 | 16K / 32K / 64K / 128K / 256K | 64K | 有存储数据时禁用；256K 应用须确认 |

### 磁盘与分区

| 字段 | 控件 | 默认 | 何时灰 / 禁用 |
| --- | --- | --- | --- |
| 分区表 | GPT / MBR | GPT | 已初始化后只读灰 |
| 文件系统 | NTFS / ReFS | NTFS | 自动创建分区关闭时禁用；SKU 不能建 ReFS 则禁用 ReFS；有存储数据时只读灰 |
| 分配单元 | 4K / 8K / 16K / 32K / 64K | 64K | 自动创建分区关闭时禁用；有存储数据时只读灰 |

多于一个用户分区：文件系统、分配单元只读灰。

## 4. 拓扑

- 拖入池 = 数据盘，按介质进实体层。
- 实体层只在有数据盘时画。
- 热备、退役模拟层仅开关打开时画，打开时无盘也画。
- 撤销/重做/放弃/应用覆盖拓扑拖盘。

## 5. 工作项

| ID | 工作 | 检查 |
| --- | --- | --- |
| SC1 | 右上四行按钮，含撤销/重做/放弃全部/应用全部 | 十个按钮都可见；禁用规则符合 §2 |
| SC2 | 右下项-值、组间缝、整行保存池属性；有层才出层字段组 | 布局符合 §3 |
| SC3 | 显示热备/退役开关；拖入模拟层 | 开关关且无盘则不画；拖入即进入该状态 |
| SC4 | 仅无虚拟磁盘时创建；可删最后一块 | 已有盘则创建禁用；最后一块可删 |
| SC5 | 新控件测试；原生打开存储结构页 | 点名测试通过；原生：启动 → 该页 → 进程仍活 → 无新崩溃日志 |
