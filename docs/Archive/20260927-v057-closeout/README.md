## 独立判断与修复

审查线索来自 `docs/Review` 的 GPT、Grok、Zcode、DeepSeek 四份 2026-09-24 报告；以当前源码、故障夹具和本轮证据判定，不把报告结论直接当事实。原报告与既有 evidence 保留。

| 问题 | 处理与证据范围 |
| --- | --- |
| 数据位置迁移丢失活动指针或 WAL 内容 | 指针移到标准根外，目录替换前固化旧指向；完整行摘要识别非主键变更；静止后 checkpoint；源与副本不一致时拒绝并保留源；双向往返、指针提交失败、读者占用及 WAL 更新由真实 SQLite 夹具验证。 |
| 构建删除运行树、便携数据和证据 | SHA-256 并集检查后才发布，旧树移入项目根 Rubbish，便携 Data 复制保留；Rebuild 在成功前保留旧运行树；Clean 只移动明确生成物；限定 checkout 路径并拒绝祖先 junction。独立脚本夹具验证碰撞、占用、Data/证据保留及路径拒绝。 |
| 非法导入与模拟规则分叉 | 导入保存前拒绝可证明的非法几何；分别判断已知字段，保留合法缺失事实；容量溢出返回参数拒绝；页面和后端共用非系统 Primary/BasicData 格式化资格；冲突、取消和持久化错误分别返回。 |
| 偏好丢更新与刷新假成功 | 偏好在同一串行门内读取最新值、变更、保存和发布；手动刷新明确 Completed/Failed/Skipped/Canceled，陈旧结果也返回 Skipped；错误或跳过不发硬件刷新成功。 |
| 停止后无法导出 | 保留本次 App 观察到的最近监控会话；停止及空快照不清除导出 ID；零行不覆盖目标文件。真实窗口停止后经系统保存框导出 18,936 行 CSV。 |
| IPC 超时和提升权限边界 | 接受后的空闲/半帧连接有 30 秒读取期限，响应写出独立限时；客户端 25 秒复用期限在写入前主动重连，已发出请求不重试；实际令牌完整性阻止较低级别客户端控制提升 Agent。 |
| CSV 路径、可恢复 UI 异常 | 普通绝对路径及 UNC 保留，拒绝设备路径、ADS、保留名等异常组件；Explorer、监控导出和异步入口捕获既有可恢复错误并报告。 |
| 窄窗、无障碍、欢迎与现行文档 | 小于 1280 DIP 使用导航菜单，480 DIP 保留系统身份和模式开关；名称跟随语言及容器重建；欢迎内容准确说明只读/模拟及权利；当前文档同步，旧实测记录保持原样。 |

未直接采纳的结论：畸形握手会永久毒化监听器、扩缩对话框没有规则预核、空虚拟盘自动分区必然因 Offset 分叉，均未得到当前代码支持。CSV ADS 的可利用性没有复现，不作为已证实漏洞；路径拒绝作为边界加固。FixedWrapPanel 的两项一列是当前布局，旧 Grid 附加属性不构成改回旧布局的依据。通知悬停策略、隐私功能、工具白名单、许可证与发布策略未因审查报告改变。
