# 当前 Plan：V0.57 实机操作前缺陷收口

状态：已完成本轮授权范围。基线 `3739691` / V0.56；目标 V0.57。2026-09-27 用户确认以下三项建议后授权执行。本轮结束后才进入真实编辑阶段。

## 本轮固定决定

- 修复经源码与直接回归核实的现有缺陷，进行只读与模拟验收，不接通真实存储写入。
- 保留 480 DIP 窄窗支持，提供可达的紧凑导航和系统上下文。
- 保留自定义 7-Zip 与 CSV 自选位置；加固 IPC 权限和路径边界，不添加工具签名/哈希白名单或固定导出目录。
- 标准运行树为 `artifacts/Release`；已有用户报告、开发数据与测试证据保留。历史验收结果不追溯改写。

## 下一阶段：本机真实存储编辑（未激活）

状态：阶段边界已确定，实施尚未开始。本轮不构成真实操作授权；开发 Agent 每次实际操作前仍按 AGENTS 核对准确目标并取得批准。上一阶段计划已[归档](Archive/20260924-before-real-edit/README.md)。

### 范围

- 为存储结构编辑页和磁盘分区编辑页现有的编辑功能接通本机真实执行；保留模拟编辑，不增加自由形式存储命令。

### 固定边界

- 本阶段只在 `DESKTOP-BLE6H18` 开发和验证。仅 `WDC WD40EZAZ-00SF3B0` 可作为破坏性操作目标；允许清理其数据、分区和磁盘结构，允许修改仅涉及该盘的池与层。
- `Samsung SSD 980 PRO 1TB` 和 `Samsung SSD 980 1TB` 禁止写入；任何可能连带修改这两块盘的池、层或其他操作也不得执行。写入前以实时事实核对本机、唯一磁盘身份与关联成员，无法确认时停止。
- 上述机器和磁盘清单仅约束本阶段开发验证，不写入软件源码或产品通用操作规则。产品内真实操作仍须由用户当次明确选择、预览并确认，再由受控 Agent 执行及重新采集核对。
- 更多真实物理机的适配与验证留到后续阶段。

### 完成标准

- 两个编辑页现有操作的真实执行链路在本机完成，并在获准的 WDC 磁盘上验证；结果经重新采集核对。未验证的操作不计为完成，Samsung 两盘保持未修改。
