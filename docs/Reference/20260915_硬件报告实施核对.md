# 2026-09-15 硬件报告实施核对

本轮从正式 Plan 基线 `ba09735` 执行，产品版本保持 V0.52。WinPool 只读核对 `Program/KS/StatSys.py` 与 `Full.yaml`，将所需能力接入现有 App + Agent、来源事实和报告投影；运行时不依赖 KS。本轮没有真实存储写入，内部格式保持 SQLite 16 / IPC 7 / StorageSystemDocument 3 / 来源事实 1。

## 字段与能力对应

| 报告区域 | KS 与既有能力 | 本轮统一事实与投影 | 关联、单位与边界 |
| --- | --- | --- | --- |
| Computer / System / Mainboard | KS WMI；现有 CIM、注册表、会话与系统补充 | 沿用 `Win32_ComputerSystem`、`Win32_OperatingSystem`、`Win32_BaseBoard`、`Win32_BIOS` 等来源；新增 `WinPool.Platform.BiosMode` | BIOS 模式由 `GetFirmwareType` 读取；激活、用户、语言、电源计划保持来源原值与状态 |
| CPU | KS `Win32_Processor` / `Win32_CacheMemory`；当前事实已保存两类对象 | `HardwareReportProjector` 分别呈现处理器与 L1/L2/L3 汇总 | 仅单处理器时汇总 L1；多处理器缺少可靠缓存归属时明确不可用，不按顺序猜测 |
| Memory | KS 物理内存阵列与模组；当前事实已有数组、模组 | 总体与模组分段；数组汇总插槽，模组统计已用插槽，ECC 支持一致、混合和未知 | 不把总体字段挂到首个模组，不按列表位置拼接阵列与模组；容量用 bytes，速度保留来源单位 |
| VirtualMemory | KS 页面文件配置；当前 CIM 设置与使用量 | 优先配置值，缺失时保留使用量来源及选值说明 | 配置值与运行时使用量不混写；位置保持原值 |
| Storage | 当前统一存储来源事实与分区联合体 | 新增 `ManageSystemSummaryProjector`，管理页和硬件页共用 7 项摘要 | 以各类最新来源状态判断已知性；成功空集合为零，失败或未采集为未知；容量用 bytes |
| GPU | KS DXGI；当前仅有 Win32 显卡补充 | 新增只读 DXGI/D3D12 来源 `WinPool.GraphicsAdapter`、`WinPool.GraphicsOutput`，报告优先使用原生事实 | 适配器用 LUID 身份；专用、共享、总显存为 bytes；DirectX 为功能级别。驱动与位置仅在 PCI VEN/DEV 唯一匹配时补入，不按名称猜测 |
| Monitor | KS DXGI 输出与 EDID；当前已有 `WmiMonitorID` | 原生输出保存坐标、分辨率、刷新率、位深、色彩空间、动态范围，并建立 `graphics-output` 关系 | 输出关联到所属显卡；EDID 仅按硬件 ID 匹配；负坐标保留，不把一块显卡的值复制给全部显示器 |
| Network | KS 网卡、地址与默认路由；当前事实缺少本机接口归属 | 新增 `WinPool.NetworkAdapter`，保存接口名/说明、速度、IPv4/IPv6、MAC、主网络和状态 | 接口 ID 为身份；网关存在用于主网络判断；速度为 bits/second；枚举失败不保留半批对象，负速度明确不可用 |

上述表区分了既有来源事实、新移植的只读能力和新投影接线。实际平台不支持、查询失败或无法可靠关联时保留来源、时间和原因；不以零值或猜测关系补齐。页面属性详情显示标准字段、原值、类型、单位、读取状态、来源和观察时间。采集、缓存、IPC、复制及完整 JSON 导出不做脱敏或字段裁剪。

## 实施与验证结果

- 硬件页改为 Computer、System、Mainboard、CPU、Memory、VirtualMemory、Storage、GPU、Monitor、Network 十段纵向报告。每段横向容纳多设备，页面纵向滚动；Memory 总体与模组分开。刷新只针对本机，操作中可取消；导出复用完整系统 JSON。
- `PropertyTableVisuals` 只复用管理页和硬件页需要的单元格样式与尺寸，没有引入通用表格引擎。英文导航在 1440 像素窗口使用紧凑模式，避免活动系统标记被截断。
- 自动验证：`dotnet restore`、全套 546/546 测试、Release 构建均通过，构建 0 警告、0 错误；依赖审计未发现已知漏洞包。测试覆盖报告顺序与分段、多模组、负显示坐标、DXGI/网络现场采集、摘要的未知/成功零值/新失败覆盖，以及分区联合体回归。
- 原生 WinUI：隔离运行目录中通过中文深色和英文浅色整页检查；本机刷新按钮在运行中切换为取消并完成恢复；4 个内存模组、多个 DXGI 适配器、2 个显示输出和本机网络接口均呈现。第二显示器保留 `Y=-620`。属性单元格可聚焦，Enter 打开详情，自动化名称包含大类、字段和值。
- 系统切换在 Local 与 Simulation 间更新活动系统标记；窄窗为紧凑导航，Network 段可横向滚动。保存选择器取消后不显示成功；完整导出生成文档 3 JSON，保留 37 个来源、120 个对象、31 条关系和原值。
- 本机两个显示器本轮均为 96 DPI，因此 192 DPI 原生布局为 `unverified`。这些检查不代表全部 GPU、显示器、网卡、Windows 版本或长期可靠性验收。
