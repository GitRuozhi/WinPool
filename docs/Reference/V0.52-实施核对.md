## 来源及退出内容

- Storage Management CIM/Storage cmdlet 保留标准属性、原始类型、枚举/数组、字节精度及时间；独立采集虚拟磁盘和层，关联失败不以介质相同猜层成员。无可靠层成员关联显示“层归属未知”。
- Win32/WMI 保留 Computer/OS、处理器、内存、分页、显示、网络、电池、逻辑盘等观察；WindowsForms 屏幕、注册表系统版本/显存、Windows 会话等补充来源保留。屏幕和监视器不按数组位置拼接，原生观察不冒充 CIM 原值。
- 普通名称、描述、路径、扩展字符串保留；硬件标识脱敏。来源详情、复制、数据库和导出遵守相同边界。
- RawSnapshot.cs、RawHardware.cs、HardwareReportFactory.cs、KsReferenceReportFactory.cs、WinPoolSystemCopy.cs 移到项目根 `Old/20260914_WinPool_V052_retired/Program/WinPool/src/`。逐文件 SHA-256 前后一致，源消失且目的存在，无覆盖；它们不是运行或构建依赖。
