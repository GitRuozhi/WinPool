## 已实施改动

1. 联机/脱机改为按模拟文档和 OS 磁盘保存的应用会话临时状态，不写数据库；脱机磁盘及其关联对象只读，只保留联机入口。
2. 管理页跳转分区页携带目标 ID；RAW 才能初始化，MBR 才能破坏性转换为 GPT，含数据时统一确认。
3. 选中 GPT 磁盘可进入最大未分配区域的新建模式；支持基本数据、EFI、MSR、Windows 恢复四种固定 GPT 分区类型，不开放自定义 GUID 或 MBR 类型。
4. 建池拆为创建池及层、创建虚拟磁盘、创建分区三个连续动作；允许正式应用没有成员且没有虚拟磁盘的空池。
5. 管理页和结构页统一显示热备、退役、未划层；热备和退役磁盘不再落入未划层。
6. 同行对象换行在既有可行行数内平均分配；不增加布局期度量、嵌套规划或固定像素替代。
7. 修复 MAX 被非法手工值、含数据控件门、延迟 `TextChanged`、显示舍入和可空层参数拦截；含数据层只允许通过 MAX 扩大，手工容量、缩小和层参数修改继续拒绝。同步修复状态文字覆盖虚拟磁盘名、拖盘到“+”未加入新池，以及退役/热备按钮与拖放路径不一致。
8. 统一按钮名称和管理命令面；“重命名分区”改为“修改卷标”，隐藏没有实际操作能力的管理命令。
