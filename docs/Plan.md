1. 先记录所测ZIP／hash、Windows版本与SKU、测试环境、时间及对应场景；缺失或混包时向用户核实，不重命名旧证据冒充新结果。
2. 只读用户提供或本机已产生的日志、会话及归档，按下表核对范围。监控数据根先核对实际位置指针，不硬编码读取旧标准目录；运行中的监控不主动停止。
3. 将实际通过／失败／缺失项及原始证据链接更新到Quality，再勾选对应待办。沿用已通过且仍适用的证据，不把多批用例相加称一次全套通过，不另建完成报告。
4. 若发现已批准范围内的产品缺陷，列明具体修复步骤并做相关回归；已公开的V0.63资产不静默覆盖，修复另行推进版本并绑定结果。涉及新产品语义、新设备授权或范围冲突时先询问用户，不从历史计划自动扩大任务。
