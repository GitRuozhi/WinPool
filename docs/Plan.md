## 1. 目标与禁止扩张

把磁盘分区编辑做成**格式化与卷属性页**：动作和属性当场提交到当前仿真文档，并弹出成功或失败。扩展/收缩只占位。

固定边界：

1. **不加入、不调用真实存储写操作。** 不创建 V0.5x 写入适配器。自由形式命令仍禁止。
2. **不改结构页的统一草稿。** 撤销/重做/放弃/应用全部、属性确认、`SimulationDraftPlanner` 批量预览仍只属于存储结构编辑页。
3. 不升 schema / IPC / 文档 / 快照编号。快速格式化在仿真中与完整格式化走同一 `FormatPartition`，不为此增加持久化字段。
4. 不改拓扑布局引擎、硬件页、监控、设置、建池向导。不把分区页扩成第二个管理检查器。
5. 不实现扩缩容算法，不调用 `ExtendPartition` / `ShrinkPartition` 的模拟改大小路径。
6. 不恢复新建 MBR、动态磁盘、VHD、FAT/FAT32、挂载路径、标为活动、优化/修复/检查错误。
7. 不以本页及时生效为由让结构页也改成点一下就写入。

## 2. 必须固定的交互与规则

执行者可调整私有拆分和控件命名，下列含义不得自行变更。

### 2.1 两页提交方式

| 页 | 提交 |
| --- | --- |
| 存储结构编辑 | 继续统一草稿：成员与参数一次预览、一次应用 |
| 磁盘分区编辑 | **及时生效**：每个允许的动作单独校验、单独经 Agent 提交、单独弹出成功或失败。无撤销/重做/放弃/应用全部，无“保存属性” |

分区页不得再把操作只写进页面工作副本、等“应用全部”才持久化。当前 `ApplyLocal` + 页面撤销栈退出。校验仍走 `StorageEditRules`；Agent 在提交前重验；失败不产生部分模拟文档。结果未知仍按 V0.48 对账，不得当成“未改变”。

非仿真（本机只读）：除「打开资源管理器」外，右上和右下全部禁用。

### 2.2 页面结构

左：拓扑。右上：动作。右下：分区/卷属性。无底栏。

拓扑（已有行为，保持）：

- 两层：磁盘，以及其上的分区和未分配空隙。空隙要能选中。
- 只画原始池中的物理盘对应 OS 盘，以及各池虚拟磁盘对应 OS 盘。入池物理盘不画。
- 系统/启动/EFI/MSR/恢复分区要画；破坏性动作禁用。
- 不拖盘入池，不拖分区边扩缩。

右上动作默认都显示，不能做的禁用。组内从左到右，组与组从上到下：

```text
联机    脱机    初始化    转换为 GPT
新建分区    删除分区    扩展    收缩    打开资源管理器
```

| 按钮 | 禁用 | 行为 |
| --- | --- | --- |
| 联机 | 未选盘、已联机，或非仿真 | 立即提交联机 |
| 脱机 | 未选盘、已脱机、系统/启动盘，或非仿真 | 立即提交脱机。页面文件/转储先确认去掉角色 |
| 初始化 | 未选盘、已有分区表，或非仿真 | 写成 GPT。没有 MBR。成功/失败对话框 |
| 转换为 GPT | 未选盘、已是 GPT、盘上还有分区，或非仿真 | 空盘转 GPT。不能转 MBR |
| 新建分区 | 未选未分配空隙，或非仿真 | 按右下容量在空隙创建。文件系统不是「不格式化」时按右下规格格式化 |
| 删除分区 | 未选用户分区，或非仿真 | 有数据须确认。EFI / MSR / 恢复禁用 |
| 扩展 | 见 §2.4 | 占位：说明尚不支持，不改大小 |
| 收缩 | 见 §2.4 | 占位：说明尚不支持，不改大小 |
| 打开资源管理器 | 仿真；或本机无盘符、RAW、脱机、路径不存在 | 仅本机：用现有 App 方式打开该卷。不是存储写操作，不经 Agent 模拟提交 |

右下顺序固定，项-值。磁盘没有属性区。最后一行整宽 **格式化**。

| 字段 | 控件 | 默认 | 何时灰 / 禁用 |
| --- | --- | --- | --- |
| 盘符 | 无 / 空闲 D–Z | 下一个空闲 | 无卷或非仿真时禁用；已被占用的不出现。选定后立即提交 `ChangeDriveLetter`，不必格式化 |
| 卷标 | 文本 | 当前标签，无卷则空 | 无卷或非仿真时禁用。确认输入后立即提交 `Rename`（Enter 或失焦；不按每个按键提交） |
| 容量 | GB | 空隙=Max；已有分区=当前大小 | 本阶段只给新建分区用。已有分区显示当前大小，不拿它做扩缩容 |
| 文件系统 | NTFS / ReFS / exFAT / 不格式化 | NTFS | 非仿真禁用。「不格式化」时格式化按钮和分配单元、快速格式化禁用 |
| 分配单元 | 4K / 8K / 16K / 32K / 64K | 64K | 「不格式化」或非仿真时禁用 |
| 快速格式化 | 开关 | 开 | 「不格式化」或非仿真时禁用 |

**格式化：** 用当前文件系统、分配单元、快速格式化开关格式化选中分区。有数据须确认。系统/EFI/MSR/恢复禁用。ReFS 先确认（研究证据不足，不是 SKU 禁令）。选「不格式化」或未选用户分区时禁用。完成后必须弹出成功或失败，快速格式化同样弹，不得静默、不得写成空操作。

仿真中快速与完整格式化都更新卷的文件系统、簇和可用空间语义；不声称耗时或介质擦除差异。真实格式化差异留给 V0.5x。

### 2.3 文件系统

本页模拟格式化/新建带格式化时，**NTFS、ReFS、exFAT 均允许**。不再用 SKU 把 ReFS 或 exFAT 做成点了被拒的死选项。NTFS 仍为默认。ReFS 没有与 NTFS 64K 同等的长期测试证据，格式化前确认；该警告不等于禁止。

旧规则「ReFS 仅 Server SKU、exFAT 一律拒绝」在本页创建/格式化路径上废止。读取已有系统时仍如实保留其文件系统，不因本页能创建某种格式就改写采集结果。

结构页建池默认分区仍为 NTFS 64K，不因本页支持三种格式而改掉建池默认值。结构页若仍列出 ReFS，继续走其现有确认；不在本阶段重做结构页格式清单。

### 2.4 扩缩容占位

扩展、收缩按钮保留。不实现改大小。不得调用现有 `ResizePartition` 去“先改再被规则挡住”。点击后说明尚不支持（无 Windows supported-size 依据），文档不变。

### 2.5 操作与结果

继续使用现有类型化 `SimulationEditKind`：`SetDiskOffline`、`InitializeDisk`、`ConvertDisk`、`CreatePartition`、`DeletePartition`、`FormatPartition`、`ChangeDriveLetter`、`Rename`。打开资源管理器不是其中一项。

每次成功或失败都要让用户看见。破坏性操作先确认。本机真实系统上这些写入仍拒绝。
