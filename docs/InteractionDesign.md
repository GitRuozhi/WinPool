# WinPool 界面交互细节

状态：2026-09-23 当前界面设计；自动回归和隔离构建已通过，卡片运动的原生画面仍 `unverified`，证据见 [Quality](Quality.md)。本文记录可直接用于开发和验收的控件、反馈与布局细节；产品支持范围见 [Product](Product.md)，技术所有权见 [Development](Development.md)，模拟操作规则见 [SimulationEditingDesign](SimulationEditingDesign.md)。未列出的页面沿用现有实现，不因此新增入口。

## 按钮、图标与悬停说明

可点击的页面按钮采用图标在左、文字在右的结构。现有页面使用约 14 DIP 的 `FontIcon`；图标只帮助辨认，文字和 `AutomationProperties.Name` 才表达完整动作。中英文切换同时更新可见文字、自动化名称和悬停说明。不可只凭颜色或图标区分可用、禁用和危险动作。

下表固定本轮相关操作的图标语义；同一动作从管理页跳转到编辑页时保持同一含义。码位是当前 Segoe Fluent 图标码位，不作为业务规则。

| 区域 | 动作 | 图标码位 | 交互 |
| --- | --- | --- | --- |
| 管理 | 刷新本机、导入模拟系统、导出模拟系统、删除模拟系统 | `E72C`、`E8B5`、`EDE1`、`E74D` | 刷新只读；导入和导出使用 JSON 文件；删除前确认目标 |
| 硬件 | 刷新/取消、导出报告 | `E72C`/`E711`、`EDE1` | 刷新仅本机；模拟系统可导出已有报告 |
| 结构编辑 | 撤销、重做、放弃、应用 | `E7A7`、`E7A6`、`E711`、`E73E` | 应用前按同一类型化计划预检查 |
| 结构编辑 | 新建池/虚拟磁盘、解散/删除、保存参数 | `E710`、`E74D`、`E74E` | 按当前对象资格启用；禁用时说明具体原因 |
| 分区编辑 | 联机、脱机、初始化、转换 GPT | `E8FB`、`E8AE`、`E9CE`、`E8AB` | 本机对象仅查看，不触发真实结构修改 |
| 分区编辑 | 新建、删除、扩展、压缩、格式化 | `E710`、`E74D`、`E8A5`、`E73F`、`E9CE` | 分区页一次动作一次模拟提交，失败不报告成功 |
| 分区编辑 | 恢复建议值、打开资源管理器 | `E777`、`E838` | 恢复按钮仅处理对应参数；资源管理器仅用于可访问的本机卷 |
| 监控 | 自动配色、事件、导出 CSV | `E790`、`E7B5`、`E74E` | CSV 只包含当前活动库的可用记录 |
| 设置 | 打开数据/工具路径、恢复默认、反馈 | `E8B7`、`E777`、`E8F2` | 打开路径不运行外部工具 |
| 开发页日志 | 复制全部、清空消息、复制 Diagnostics 路径、复制详情 | `E8C8`、`E74D`、`E8C8`、`E8C8` | 复制保留完整文本；清空只影响本次运行历史 |

`ContextHelp.Set` 为可用控件说明用途、参数、单位与限制；`ContextHelp.SetDisabledReason` 给出本次选择下的实际禁用原因。禁用控件由 `ContextHelpHost` 提供透明悬停命中区，不为了说明原因重新启用操作。提示文本换行且宽度有界；键盘和辅助技术通过 `AutomationProperties.HelpText` 获得同一含义。分区页的完整/快速格式化开关都需要说明：只影响模拟格式化意图，不扫描或改动真实磁盘。

## 右下角消息卡

消息卡停靠主窗口右下角；单卡固定 384×128 DIP，卡间距 6 DIP，新增卡片也不因标题或正文长短改变尺寸。标准窗口最多显示三张；窗口高度不足时按可用高度减少同时显示数，至少保留一张。新增消息挤出最旧的可见卡，但其已完成消息仍留在本次运行记录。卡片文字在固定区域内截断或裁切；完整消息通过错误点击对话框或开发页日志详情取得。卡片使用现有主题资源，不自行硬编码亮色/暗色背景。

| 事件 | 卡片与记录 | 结束方式 |
| --- | --- | --- |
| 普通完成、警告 | 每次独立事件各有卡片及历史条目；不按相同文字合并 | 8 秒后或点击后退出 |
| 错误 | 卡片提示到开发页查看详情；点击弹出可读的错误对话框 | 20 秒后退出；点击不丢失历史 |
| 正在进行的采集 | 同一进度键更新卡片，不进入历史 | 完成、失败、取消或结果未知时移除，再发布相应结果 |
| 持续监控异常 | 状态第一次变化时发布；同一异常轮询不重弹 | 卡片退出不代表异常已恢复；恢复另按状态变化处理 |

所有卡片退出路径使用向右平移 420 DIP、240 ms 后消失的同一呈现动作，包括点击、到期、进度结束和被新卡挤出。退出动画完成后才移除视觉对象；动画完成回调失联时 UI 层用 750 ms 兜底计时释放占位。此动作只影响呈现，不删除本次运行记录或更改后台状态。错误卡点击在退出后显示消息对话框。系统关闭动画效果时直接完成离场与占位释放；通知服务只维护消息生命周期。

## 何时弹消息

| 来源 | 触发点 | 不触发的情况 |
| --- | --- | --- |
| 自动库存采集 | Started 显示进度；已验证并应用新文档后报成功；失败报失败并保留旧事实 | 加载上次历史、晚连接补读、同一次手动采集的 Agent 重复事件 |
| 手动库存/硬件刷新 | 请求开始显示独立进度；响应成功、失败、取消或连接异常时给明确结果 | 仅点击页面、选择对象、移动鼠标 |
| 模拟编辑 | 校验通过且事务有明确结果后报成功；明确拒绝/失败给原因；结果未知单独说明并等待对账 | 临时输入不完整、悬停、草稿选择切换 |
| 格式化 | 对现有数据先确认会清除模拟数据；选择 ReFS 时说明证据限制；提交后报告所选快速/完整意图及结果 | 用户取消确认或文件选择器时不报成功 |
| 模拟导入/导出 | 文件实际读写完成后报结果；格式、版本、身份或权限失败给错误 | 仅打开或取消文件选择器 |
| 监控与归档 | 真正进入故障、记录缺口或恢复状态时报告；保留故障历史 | 正常采样轮询、正常窗口淘汰、重复读取同一持续状态 |

已完成事件的正文、来源、时间及必要详情进入内存中的本次运行记录，容量上限为 200。清空记录不关闭活动卡，也不宣称故障恢复。悬停、选择和普通进度变化不写入历史。通知与对话框用途不同：卡片用于异步结果，确认对话框用于提交前选择，错误对话框用于阅读错误正文。

## 开发页布局与日志交互

开发页不显示页面大标题。上方两列：左上为“日志”，右上留空；下方横跨两列，内容留空并以小号次要文字显示“人工智能入口，功能正在开发中。”英文界面给等义文字。三个区域使用同一主题卡片背景、1 DIP 边框和 4 DIP 圆角，区域之间留 16 DIP 间距；布局宽度小于 760 DIP 时隐藏右上空区，让日志区横跨上方。文字与列表随列宽收缩，不以绝对坐标定位。

左上日志区列出本次运行的内存消息条目（时间、级别、来源、标题/摘要）；双击条目弹出同窗口详情，可选择并复制正文。复制全部、清空记录和实际 Diagnostics 路径复制继续放在日志区，路径显示不读取或创建日志文件。详情使用既有串行 `ContentDialog` 协调，不能因连续双击出现重叠对话框。当前日志来源的产品边界见 [Product](Product.md)；未来若接入磁盘日志，需要另行定义读取、筛选和生命周期，不把路径显示偷换成文件内容。

## 验收观察点

- 中英文、常见长消息和错误提示下，三张卡外形相同；点击、超时和挤出均向右离场，历史仍在。
- 页面按钮具有可辨认图标、文字、用途提示和具体禁用原因；禁用按钮仍可悬停。
- 开发页首屏无大标题，三块区域位置正确；双击条目打开详情，正文可复制；右上无功能，底部仅有指定提示。
- 取消导出不生成成功卡；系统导出只以 `.json` 保存标准 JSON 文本。
